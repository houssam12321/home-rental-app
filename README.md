# 🏡 DreamHome Real Estate Backend

A **Spring Boot** backend application for managing **real estate properties** — allowing users to list, view, and manage property ads for **sale** or **rental**.  
The backend is built with **Java 17**, **Spring Boot**, **Spring Data JPA**, and **PostgreSQL** as the database.

---

## 🚀 Features

- CRUD operations for property listings  
- RESTful API architecture  
- PostgreSQL database integration  
- Layered architecture (Controller, Service, Repository, Model)  
- Exception handling and validation  
- CORS enabled for frontend connection  
- Ready for containerization and deployment (e.g., Docker, Azure)

---

| Layer | Technology |
